# Pre-plan

Discuss the problem so you consolidate a precise understanding of it.

- Has any open questions/doubts? Ask all open questions in layered batches.
- Has no questions? State it -> prompt user for next step.

When finished, DO NOT jump to implementation.

## Output

When finished, write (to output, not file system) a structured/organized and minimal (i.e. as small as possible) yet complete (i.e. has all essential information) of your problem understanding.
