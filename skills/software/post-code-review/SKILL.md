## Post Code Review

Do:

1. Perform a code review, looking for:
   - Refactor candidates according to skill: /simple-refactor.
   - Security issues.
   - Bugs for confirmed requirements.
   - Unhandled errors.
   - Missing test behavior coverage.

2. List all your findings to the user:
   - Divided in categories.
   - Each finding should have proposed solution and explanation.
   - If you have questions, ask before proposing a compatible/correct solution.
