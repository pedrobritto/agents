# Post Code Review

Review current branch..HEAD diff for:

- Refactor candidates: simpler flow, clearer names, needless abstraction.
- Security issues.
- Bugs against stated requirements.
- Unhandled errors.
- Missing behavior test coverage.

Report findings by category, each with explanation and proposed fix. Unclear intent → ask before proposing.
