# Mission: Relational database systems

## Why
Build a rigorous foundation that supports designing production databases, reasoning about correctness and concurrency, and diagnosing query performance instead of relying on memorized ORM patterns.

## Target scope
Advanced competence in the core of relational database systems, with intermediate practical PostgreSQL specialization.

## Success looks like
- Design relational schemas and defend keys, constraints, and normalization decisions.
- Write and reason about non-trivial SQL.
- Explain transaction anomalies and choose defensible isolation/concurrency strategies.
- Select indexes from workloads and validate performance hypotheses with query plans.
- Explain the main responsibilities of a relational database engine well enough to debug behavior.

## Constraints
- Prefer short interactive sessions.
- Prefer production-oriented examples.
- External university/textbook assessments are welcome.

## Out of scope
- Deep distributed database implementation.
- Specialist database kernel development.

## Assessment preference
Use independent university problem sets/exams and practical PostgreSQL tasks where possible.
