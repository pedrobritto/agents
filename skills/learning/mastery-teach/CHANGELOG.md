# Changelog

## 1.0.0 — 2026-08-22

Initial Mastery Teach design.

- Preserves mission-driven, source-grounded, persistent tutoring ideas from Matt Pocock's `teach` skill.
- Adds researched competency graphs and prerequisite-aware unlocking.
- Adds separate domain and learner models.
- Adds proficiency levels 0–4 with evidence confidence and retention state.
- Adds independent/external assessment catalog and attempt provenance.
- Adds adaptive initial diagnostic.
- Adds curriculum versioning and auditable map changes.
- Adds workspace validation and Mermaid map rendering scripts.
- Includes a deliberately incomplete database-systems example to demonstrate the mechanics without pretending to be a researched full curriculum.
