# Lessons and reference artifacts

The conversation is the live tutoring surface. Files are durable memory.

## Lessons

Create a lesson in `lessons/NNNN-<slug>.html` when the content is worth revisiting as a coherent short unit.

A lesson should:
- target one competency or tightly coupled micro-set;
- connect to the mission;
- cite trusted primary/high-quality sources;
- explain intuition before detail;
- contain at least one active task;
- reuse `assets/` when applicable;
- link to relevant reference documents and adjacent lessons;
- remain printable/readable.

Do not create a lesson merely to archive chat.

## Reference

Create compressed reusable material in `reference/`.

Good candidates:
- glossary;
- syntax/reference tables;
- diagnostic algorithms;
- flowcharts;
- formula sheets;
- conceptual diagrams;
- error-pattern guides.

The glossary is canonical language for the workspace.

Add a term only after the learner has enough understanding for the definition to be meaningful. Revise definitions when understanding deepens.

## Working memory rule

A durable artifact can be comprehensive. A live lesson should not be.

During teaching, reveal the smallest coherent amount needed for the next successful action.
